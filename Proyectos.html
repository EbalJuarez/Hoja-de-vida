Página web de boletos en Razor
C# HTML CSS

Proyecto enfocado en el desarrollo de una plataforma web para la compra y gestión de boletos en línea. El sistema permite a los usuarios consultar eventos disponibles, seleccionar sus boletos y realizar sus compras de manera rápida y sencilla. Además, busca ofrecer una experiencia segura, organizada y accesible para facilitar la administración y venta de entradas.

MP3 en Java
Java

Proyecto desarrollado en Java inspirado en plataformas de música como Spotify. El programa permite a los usuarios explorar canciones, crear y gestionar listas de reproducción, reproducir contenido musical y organizar sus canciones favoritas. Este proyecto busca poner en práctica conceptos de programación orientada a objetos, manejo de interfaces y gestión de datos, creando una experiencia sencilla y funcional para la reproducción de música.

Programa para validar Carnets
C#

Proyecto desarrollado en C# que consiste en la creación de un navegador web con una interfaz sencilla e intuitiva. El programa permite a los usuarios acceder a diferentes páginas de Internet, navegar entre sitios y utilizar funciones básicas de navegación. Este proyecto permite aplicar conocimientos de programación, diseño de interfaces y manejo de componentes web dentro de un entorno de escritorio.
