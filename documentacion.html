Integracion de bootstrap


        <head>

        <meta charset="utf-8">

        <meta name="viewport" content="width=device-width, initial-scale=1">

        <title>Documentacion bootstrap</title>

        <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">

Esto es importante de incluir dentro de nuestro head para que el navegador descargue todos los elementos de bootstrap

Breaskpoints

Los breaskpoints nos sirven para dimensionar nuestra pagina web dependiendo del tamañano de la pantalla en la que se vera

Breakpoint Prefijo Para
Extra small — <576px / Móviles
Small sm ≥576px / Móviles grandes
Medium md ≥768px / Tablets
Large lg ≥992px / Laptops
Extra large xl ≥1200px / Monitores
XXL xxl ≥1400px / Pantallas grandes

Rejillas

Los principales componentes para las rejillas son: 

            
            <div class="container">
            <div class="row">
                <div class="col-md-6">Mitad izquierda</div>
                <div class="col-md-6">Mitad derecha</div>
            </div>
            </div>

Row, Col, Container se mezclan con Breakpoint para que la pagina sea responsiva. Es un poco dificil de entender como funcionan los prefijos dentro de las columnas

Mitad izquierda
Mitad derecha

Un extra, se pueden usar margenes y paddings en las columnas:

            
                <div class="p-3">
                Padding en todos los lados
                </div>

                <div class="px-3">
                    Padding horizontal
                </div>

                <div class="py-3">
                    Padding vertical
                </div>

                <div class="m-3">
                    Margin en todos los lados
                </div>

                <div class="mx-3">
                    Margin horizontal
                </div>

                <div class="my-3">
                    Margin vertical
                </div>

Navbar

Nos permite navegar en un conjunto de opciones y es dinamica. Lo importante para una navegacion es usar la etiqueta "a: junto con "href"

Mi página
  • Inicio
  • Servicios
  • Contacto 

            <nav class="navbar navbar-expand-lg bg-body-tertiary">
                <div class="container">

                    <a class="navbar-brand" href="#">Mi página</a>

                    <button
                        class="navbar-toggler"
                        type="button"
                        data-bs-toggle="collapse"
                        data-bs-target="#navbarNav"
                        aria-controls="navbarNav"
                        aria-expanded="false"
                        aria-label="Toggle navigation">

                        <span class="navbar-toggler-icon"></span>
                    </button>

                    <div class="collapse navbar-collapse" id="navbarNav">
                        <ul class="navbar-nav">

                            <li class="nav-item">
                                <a class="nav-link active" href="#">Inicio</a>
                            </li>

                            <li class="nav-item">
                                <a class="nav-link" href="#">Servicios</a>
                            </li>

                            <li class="nav-item">
                                <a class="nav-link" href="#">Contacto</a>
                            </li>

                        </ul>
                    </div>

                </div>
            </nav>
